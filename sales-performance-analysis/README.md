# Sales Performance Analysis – Excel

## Overview

An interactive sales dashboard developed in Microsoft Excel to analyze sales performance and identify key business insights.

## Tools & Techniques

* Microsoft Excel
* Pivot Tables
* Power Query
* Charts
* Slicers

## Key Analysis

* Sales performance
* Sales trends
* Sales by category
* Sales by region
* Top-performing products
